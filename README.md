# WEN MC Launcher（我的世界启动器云端后端）

- 版本清单 / 库解析（BMCLAPI + Mojang 镜像，302 直链不占自身流量）
- 皮肤上传（PNG ≤8MB）/ 读取
- 正版 / 离线登录
- 启动与安装接口（仅本机客户端可用，云端 403）
- 像素风 Web 前端（EXE / APK / 网页三态）

## 部署（Sealos）

1. 新建应用（应用管理 → 创建应用）
2. 来源：Git 仓库 → 授权 GitHub → 选择本仓库
3. 端口：3000
4. 域名：自动分配 `*.sealos.app` 免费子域名，也可绑自定义域名

健康检查：`/api/ping`
